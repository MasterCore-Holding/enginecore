# docs/ — documentação EngineCore

Documentação técnica e de operação da EngineCore.

## Convenção

- Um assunto por arquivo, nome em kebab-case.
- Todo documento declara data e autor no rodapé.
- Documento que descreve processo precisa dizer onde a evidência é verificável
  (link, caminho, comando). Processo sem evidência verificável é intenção, não norma.

## O que mora aqui

- Runbooks de operação da esteira.
- Especificações de integração (formulários, CRM, WhatsApp).
- Registros de decisão técnica.

O que **não** mora aqui: norma de governança do grupo (vive no Núcleo Universal e
nas emendas, no repositório `landing`), e conteúdo de cliente.
